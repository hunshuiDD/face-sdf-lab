# FaceWipeUI 接入

在目标 C++ 工程编译并启用 FaceWipeUI 和 FaceKeyLight。在拥有本地玩家的 PlayerController 中传入当前世界的目标 AFaceProjectActor。Blueprint 可使用 Create For Player、Add to Player Screen 和 Set Input Mode Game and UI。

```cpp
#include "FaceWipeWidget.h"

if (UFaceWipeWidget* UI = UFaceWipeWidget::CreateForPlayer(this, FaceActor))
{
    UI->AddToPlayerScreen(10);
    UI->SetPositionInViewport(FVector2D(24, 24), false);
    FInputModeGameAndUI Mode;
    Mode.SetWidgetToFocus(UI->TakeWidget());
    Mode.SetHideCursorDuringCapture(false);
    SetInputMode(Mode);
    bShowMouseCursor = true;
}
```

在调用模块的 Build.cs 添加 FaceWipeUI。滑块写入 MID 的 WipeX，勾选框更新 CompareEnable。程序驱动使用 SetWipeValue 同步滑块与材质。Actor 创建 MID 前控件等待绑定，MID 替换后会同步当前值。空目标仅在当前世界恰有一个 FaceProjectActor 时自动绑定。

在已编译插件的 Win64 编辑器工程运行自动化。测试覆盖控件事件路由、鼠标捕获、边界夹取与 MID 同步。

```text
UnrealEditor-Cmd.exe Project.uproject -NullRHI -NoLiveCoding -nosound -unattended -nop4 -nosplash -ExecCmds="Automation RunTests FaceWipeUI.PointerDragToActorMID" -TestExit="Automation Test Queue Empty" -FaceWipeReport=outputs/wipe.json -ReportExportPath=outputs/automation
```
